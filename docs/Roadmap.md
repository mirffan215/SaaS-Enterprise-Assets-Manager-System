## Decisions recorded

- **Authentication:** local accounts only. No Active Directory, Entra ID / Azure or Microsoft Graph.
- **E-mail:** SMTP (configurable relay) replaces Microsoft Graph for notifications.
- **Caching:** in-memory distributed cache by default for the single local server; Redis is a configuration switch for later scale-out.
- **Mapping:** explicit, reviewed mapping code instead of AutoMapper (recent AutoMapper versions are commercially licensed, and explicit mapping makes permission-restricted fields auditable).
- **Excel:** .xlsx files are read and written with .NET's built-in zip and XML support (Office Open XML format) - no third-party package; files are verified with an independent library in testing.
- **QR codes:** generated by a built-in encoder (ISO/IEC 18004, level M), verified module-for-module against an independent implementation and decoded with OpenCV in testing. No QRCoder package needed.
- **Barcodes:** Code 128 encoder built in (ISO/IEC 15417), verified by decoding rendered print output with ZBar at 203 and 300 dpi.
- **Labels:** printed from the browser at the exact label size on any label printer (Save as PDF available) instead of QuestPDF, which requires a paid licence for larger companies.
- **MFA:** not in v1.0 scope. The schema and security stamp design allow TOTP (authenticator app, works offline) to be added later. Plan this before go-live, as authentication strength is likely to be assessed against ISO 27001 A.8.5 and the Access Control Procedure.
